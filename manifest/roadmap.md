# SiteForge Roadmap

# Philosophy

The Factory roadmap prioritizes:
- architectural stability
- intelligence quality
- orchestration clarity
- deterministic rendering

The roadmap intentionally delays:
- frontend polish
- large component libraries
- advanced visual systems

Until:
- contracts stabilize
- orchestration stabilizes
- readiness stabilizes
- intelligence pipelines stabilize

The Factory is built:
# intelligence-first.

## Astro Rewrite
The frontend rewrite is intentionally delayed.

The previous architecture failed because:
- rendering was designed before intelligence
- schemas were driven by components
- intake attempted to satisfy frontend assumptions

The new architecture requires:
Recon →
Strategy →
Build Contracts →
Rendering

---
